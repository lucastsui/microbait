Set up Microbait

Sign in to X in Google Chrome and to LinkedIn here. Choose Grok CLI or the OpenCode API to write the briefing.

  1. X

    Opens Google Chrome to x.com. Sign in there, including with a passkey. Microbait then keeps the session.

  2. LinkedIn

    Sign in here so job ads in the report open already logged in. Uses the same session as the right-hand preview.

  3. AI

    Grok CLI is the local grok command. OpenCode API uses a key from opencode.ai/auth.
